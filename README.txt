YASMIN'S INTERNSHIP PORTFOLIO — QUICK START

1. Extract this ZIP file.
2. Open VS Code.
3. Select File > Open Folder, then choose the extracted "yasmin-internship-portfolio" folder.
4. Open index.html.
5. If you installed the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, you can open index.html directly in a browser.

FILES
- index.html : website content and sections
- style.css  : colours, layout, typography and responsive styles
- script.js  : mobile navigation interaction

BEFORE PUBLISHING — IMPORTANT
- Replace "Yasmin" if you want a different display name.
- Update the About Me text to reflect your actual experience.
- Remove technologies you have not used or cannot discuss in an interview.
- Update project descriptions with actual features and your own contribution.
- Replace the education start/graduation year placeholders.
- Replace your.email@example.com with your real professional email.
- Update LinkedIn and GitHub links to your own profiles.
- Add your PDF resume as assets/resume.pdf. If you do not have it ready, remove the resume button for now.
- Check every link and spelling on desktop and mobile.

PUBLISHING
This is a static website and can be hosted on GitHub Pages:
1. Create/sign in to GitHub.
2. Create a repository and upload index.html, style.css, script.js, README.txt and the assets folder.
3. Open the repository Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and root folder, then save.
6. Wait for the published website URL to appear in the Pages section.

Note: The portfolio contains placeholder contact details, example skills and a sample project card. Personalise these before sharing with employers.
